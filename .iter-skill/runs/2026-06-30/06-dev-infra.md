# Cluster 6: Developer + Infra — Optimization Report
Date: 2026-06-30
Scope: hamr-developer (dev tooling/portal) + hamr-infra (IaC/GitOps/observability)

## Executive Summary

- **Tooling task file is shallow but load-bearing for 14 repos**: `hamr-developer/Taskfile.yaml` (121 lines, 10 tasks) has zero `includes:`, zero `preconditions:`, zero `deps:`, no `silent:` hygiene, no per-task `dir:`, and almost every failing sub-step uses `ignore_error: true` (`Taskfile.yaml:41,44,47,105,108`) — the file gives the *appearance* of a multi-language pipeline while silently swallowing TS/Python/typedoc failures. The `verify.sh` script that supposedly catches this (`scripts/verify.sh:90`) only `warn`s and exits 0. Net effect: a TS/Python regression will never fail CI.
- **Developer portal has no governance documents at all**: no `CODEOWNERS`, no `CONTRIBUTING.md`, no `SECURITY.md`, no `docs/adr/`, no `.golangci.yml`, no `.pre-commit-config.yaml`, no `dependabot.yml`, no `LICENSE` referenced in any helm sub-chart. README claims "30 秒上手" but the only path is copy-paste boilerplate, no runbooks for production incidents, no SLOs.
- **`hamr-infra` hardcodes SOPS keys, ports, and an `admin` password in committed YAML/TF**: `.sops.yaml:9-23` ships four placeholder `age1hamr…` recipients; `tofu/envs/dev/main.tf:75` ships `grafana_admin_password = "admin"`; `argocd/appset.yaml:21-59` lists 13 service ports + 3 envs in a 42-Application matrix that is duplicated verbatim in `tofu/modules/argocd/main.tf:111-135`; `cd-deploy.yaml` uses `secrets.ARGOCD_AUTH_TOKEN` (long-lived PAT) instead of OIDC.
- **CI/CD is missing scanning, signing, and drift detection**: no `trivy`, no `grype`, no `cosign`/`slsa`, no `kubeconform`, no `checkov`/`tfsec`/`tflint`, no OIDC for ArgoCD, no scheduled `tofu plan` drift check, no `argo-cd-diff` style preview; reusable `ci-build-push.yaml` has no `attestations`/`provenance` step despite claiming supply-chain awareness.
- **Cross-repo leverage is screaming**: `hamr-developer/Taskfile.yaml` cannot be reused by the 14 subprojects because it lives next to `tools/hamr-cli` and assumes a sibling `../hamr-<svc>` checkout; the same `helm-charts/lib-common/` is declared in `argocd/appset.yaml:83` as a chart path but `helm-charts/lib-common/Chart.yaml` has zero `templates/` (it is an empty library chart). The "1 Taskfile, 14 repos" promise in `README.md:13` is unfulfilled and is the highest leverage point in the entire family.
