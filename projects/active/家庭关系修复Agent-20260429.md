## 🎯 项目概述

### 项目背景

现代家庭中，男性普遍存在"早出晚归、上班忙、顾家少"的现状，导致：
- 妻子缺乏关心，情感需求得不到满足
- 家庭矛盾频发，争吵成为常态
- 亲子关系疏远，父亲角色缺位
- 婚姻质量下降，陷入冷战和内耗

传统解决方案要么讲大道理，要么依赖玄学，缺乏可落地、可执行的具体行动方案。

### 项目目标

打造一个全自动、可执行的家庭关系修复Agent，实现：
- **主动补位**：代替用户主动关心妻子、分担家务
- **情绪兜底**：在矛盾爆发前进行情绪安抚和拦截
- **轻量顾家**：用最少的时间成本实现最大的家庭和谐效果
- **习惯养成**：帮助用户建立长期稳定的家庭参与习惯

### 项目价值

- **用户价值**：减少家庭矛盾，提升婚姻质量，改善亲子关系
- **业务价值**：填补家庭关系AI助手市场空白，具有广泛用户需求
- **技术价值**：探索AI在情感支持和生活指导领域的应用模式

## 📐 项目范围

### 包含的功能

- [ ] **核心任务1：日常关心提醒**
  - 工作日中午/傍晚定时发送关心消息
  - 消息内容简洁、不啰嗦、不解释
  - 禁止使用"我上班也很累"等反驳性语言

- [ ] **核心任务2：下班接管家务**
  - 进门强制提醒：先抱孩子/问候老婆
  - 15分钟家务/带娃任务分配（洗碗、收拾客厅、哄娃等）
  - 夜间哄睡轮换提醒（每周至少3次）

- [ ] **核心任务3：情绪矛盾拦截**
  - 识别妻子情绪信号（语气冷淡、话少、抱怨、叹气）
  - 自动触发标准安抚话术
  - 禁止辩解、抬杠、翻旧账

- [ ] **长期规划模块**
  - 事业家庭平衡建议
  - 无效社交砍掉提醒
  - 双人分工规则建立

- [ ] **每日执行清单**
  - 工作日清单：中午关心、准时下班、主动分担、睡前交流
  - 休息日清单：独立带娃、做饭打扫、深度沟通

### 明确不包含

- 不包含：婚姻咨询、心理治疗等专业服务
- 不包含：家庭暴力等极端情况处理（需转介专业机构）
- 不包含：儿童教育专业指导

## 🛠 技术方案

### 技术栈

- **前端**：React Native / Flutter（跨平台移动端）
- **后端**：Node.js + Express / Python + FastAPI
- **数据库**：PostgreSQL（用户数据）+ Redis（缓存）
- **AI引擎**：LLM（情感分析、话术生成）
- **基础设施**：Docker + Kubernetes

### 架构设计

```
用户层：移动端App（iOS/Android）
    ↓
API层：RESTful API + WebSocket（实时通知）
    ↓
业务层：
  - 关心提醒模块（定时任务）
  - 任务分配模块（规则引擎）
  - 情绪识别模块（NLP分析）
  - 话术生成模块（LLM）
    ↓
数据层：用户数据 + 家庭规则库 + 话术模板库
```

### 技术依赖

- 消息推送服务：极光推送 / Firebase Cloud Messaging
- 情感分析API：自建或第三方NLP服务
- 定时任务：Celery / Bull Queue
